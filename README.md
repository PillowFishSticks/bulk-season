# Bulk Season

A short, active incremental web game. Eat your way around a food market until your appetite runs out, then burn the calories at the gym on upgrades and go back hungrier.

## The loop

1. **Run.** Drag (phone) or use WASD/arrows (laptop) to walk into food. Each run lasts as long as your *Appetite*.
2. **Stomach.** Every bite fills your stomach and digestion slowly empties it. When it's full you can't eat until it settles.
3. **Gym.** Spend the kcal you ate on upgrades, grouped by bumper-plate colour (25kg red down to 5kg white).
4. **Go deeper.** Unlock new markets: Corner Shop → The Chippy → Curry House → Street Food → The Buffet, where the Sunday Roast boss waits (300 bites, progress kept between runs).

## Running it

It's one file with no build step. Open `index.html` in any browser, or host the repo with GitHub Pages. Progress saves in the browser's local storage.
